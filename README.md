# 🚌 Smart Student Transportation Recommendation & Analysis System

A beginner-friendly full-stack web application that collects student transportation data, performs analytics, and provides smart mode-of-transport recommendations based on distance, cost, time, weather, and travel type.

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) v18+
- A [Supabase](https://supabase.com/) account (free tier works)
- A modern web browser

### Setup

Open `frontend/index.html` directly in your browser, or use a live server:

```bash
# Using VS Code Live Server extension (recommended)
# Right-click index.html → "Open with Live Server"

# Or using npx
npx -y live-server frontend/
```

The frontend will be served on `http://localhost:8080` (default).
